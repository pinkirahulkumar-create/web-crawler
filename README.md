# 🌐 Autonomous Web & News Discovery Engine

High-performance, serverless 24/7 web crawler engine. Automatically indexes live breaking news, official government press releases, and trending tech launches directly into TiDB Cloud Serverless.

## Features
- **Live National & Global News**: Google News, PIB India, NDTV, LiveMint, TechCrunch, The Verge, BBC World.
- **Trending Tech Launches**: Hacker News live API streams.
- **Serverless & Autonomous**: Runs 24/7 via GitHub Actions cron workflows.
- **Secure Architecture**: Database credentials managed safely via GitHub Secrets and local `.env`.
